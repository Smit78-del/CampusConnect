# CampusConnect

Open `index.html` in a browser. Keep all five HTML files and `style.css` together. The home page is a landing page; the four other pages open in new tabs. This project uses only HTML and CSS.

The sample dates are illustrative. The Clubs form demonstrates inputs, a select menu, radio buttons, and a CSS-only modal; it does not submit or save data.

## Syllabus examples

- Flexbox: header, footer, class rows and landing hero.
- Grid: landing cards, detail pages and club cards.
- Media queries: the two breakpoints at 850px and 650px.
- Box model and display: shared cards and buttons.
- Specificity, cascade and inheritance: navigation active and hover rules; text colors inherited from body and dark event card.
- Positioning and z-index: sticky header, relative modal panel, absolute close button, fixed modal overlay.
- Transition and transform: hover cards and tilted landing card.
- Animation and keyframes: pulsing dot and opening modal.
- HTML lists: classes notes and event list; table: Assignments; form: Clubs.
